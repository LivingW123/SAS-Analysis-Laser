# Description of data in test_images

Each folder is labeled by the 5-digit shot number, SSSSS.
All data (as of Jul 22) is from SAS-A at LF.
Within each folder, there may or may not be the following data:

- shot0SSSSS.tif: the original data image
- shot0SSSSS-1.tif: the downsampled 48x24 data image, generated by Matthew Price
- s1final.xlsx through s5final.xlsx: the extracted lineouts from shot0SSSSS-1.tif, computed by Matthew Price. The data here have been fit with the gamma-variate form and averaged across the upper and lower half of the figure.
- SSSSS_proc_vector.csv: the 1x200 data extracted from shot0SSSSS-1.tif as a csv file, without any correction or fit
- SSSSS_proc_vector_cv.csv: the 1x200 data as above, with oversaturated pixels corrected when above 80% of the 255 pixel threshold, using a Gaussian fit on the vertical profile, found in `rescale_vector.ipynb`. NOTE: No correction is made for the gaps between blocks of 12 crystal segements. This is not correct, and may affecrt inference.
- SSSSS_proc_vector_ch.csv: the 1x200 data as above, gathered from the s1final.xlsx through s5final.xlsx files. In the data of these excel files, the saturation correction is done using a gamma-variate fit on the horizontal profile for pixels above 235 in pixel value. This data is corrected for the gaps between blocks of 12 crystal segments.
